# Fitform Industries Private Limited – Website

A responsive corporate website developed for **Fitform Industries Private Limited**, a uniform manufacturing company based in Madurai, Tamil Nadu.

The website provides information about the company, uniform categories, franchise opportunities, contact details, and enquiry options.

## 🌐 Website

Live Website: https://fitformwebsite.netlify.app/







## 📌 About the Project

The Fitform Industries Private Limited website is a modern, responsive static website designed to present the company's uniform manufacturing services and business information online.

The website is designed with a professional **dark navy, gold, and white** color theme to match the company's corporate identity.

### Main Objectives

- Present company information professionally
- Showcase different uniform categories
- Provide franchise enquiry functionality
- Provide company contact information
- Provide WhatsApp communication
- Display company location using Google Maps
- Provide a responsive experience across desktop, tablet, and mobile devices
